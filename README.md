## 完全体判定

既存の `PerformanceJudge.gs` を再利用しています。
推測値は使用しません。

曲・イベントごとに以下をAPIで返します。

- `completePerformanceCount`
- `irregularPerformanceCount`
- `unregisteredPerformanceCount`
- `completeRate`

## 最長ブランク

同一日の複数歌唱は1日として扱い、
連続する歌唱日の最大日数差を算出します。

年フィルター使用時は「その対象年内」の最長ブランクです。
全期間なら全履歴の最長ブランクです。

## キャッシュ

ランキングAPIのレスポンス構造が変わるため、
GAS側キャッシュバージョンを `v4.2.0` に更新しています。

Web側はランキング要求に `schema=4.2` を追加し、
旧ランキングのブラウザキャッシュを使用しないようにしています。
