## 変更内容

「4件の歌唱記録」のような件数表記を削除しました。

件数を表示すると、クリック先にその件数分の記録だけが表示されるように見えるためです。
実際の遷移先は、その歌唱者・歌唱名義に関連する曲・イベントの横断検索です。

変更後：

- ラベル：主な歌唱名義
- タイトル：Pile / μ's / ユニット名など
- 補足：この名義の関連曲・イベントを見る

μ'sも個人名・ユニット名と同じルールで表示します。
件数ではなく、クリック後に何が見られるかを説明する文言へ統一しました。
