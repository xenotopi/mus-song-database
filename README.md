## 実装内容

### 検索精度・並び順

検索結果を次の優先順で表示します。

1. 完全一致
2. 前方一致
3. 部分一致
4. 関連項目一致

完全一致・前方一致にはラベルを表示します。

### キーボード操作

- ↑↓：検索結果を移動
- Enter：選択中の結果を開く
- Esc：選択を解除して入力欄からフォーカスを外す

### 検索結果

- 曲・イベント・会場・歌唱名義を色分け
- 表記を「歌唱者」から「歌唱名義」へ統一
- 検索語のハイライトを改善
- タブ切り替え後もURLへ状態を保存
- ブラウザの戻る・進むに対応

### 検索履歴

- 成功した検索語を最大8件保存
- ワンクリックで再検索
- 履歴の一括削除
- スマホでは横スクロール表示

### 0件・エラー・読み込み

- 0件時の案内を具体化
- 再検索候補を表示
- 読み込み時にスケルトンを表示
- APIエラー時に再検索ボタンを表示

### スマホ

- 検索結果カードの幅を最適化
- 履歴を横スクロール化
- キーボード操作案内はPCのみ表示
