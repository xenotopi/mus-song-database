# μ's Song Database

μ'sの歌唱記録を、楽曲・イベント・会場・歌唱名義などから巡ることができる非公式ファンデータベースです。

## Webサイト

https://xenotopi.github.io/mus-song-database/

## 主な機能

- 楽曲ごとの歌唱履歴
- イベントごとの歌唱記録
- 会場ごとの開催・歌唱履歴
- 歌唱名義ごとの記録
- 歌唱回数・ランキング
- 年別の歌唱記録・統計
- 「いつ振り歌唱チェッカー」
- μ'sに関する日付別記録

## About

本サイトはファン個人による非公式・非営利のデータベースです。  
公式および関係各社とは一切関係ありません。

掲載している作品名・楽曲名・人物名等の権利は、それぞれの権利者に帰属します。
