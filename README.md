# v4.3.2：チェッカー導線・結果UI改善版

## 変更内容

### 1. いつ振り歌唱チェッカーをランキング配下から外す

変更前：
- ホーム ＞ ランキング ＞ いつ振り歌唱チェッカー
- ランキングページにチェッカー導線

変更後：
- ホーム ＞ いつ振り歌唱チェッカー
- ランキングページのチェッカー導線を削除
- ホーム「μ'sの歴史を巡る」に独立カードを追加

ホームのカード：
- 横断検索
- ランキング
- 年別統計
- いつ振り歌唱チェッカー

PC：4列
タブレット：2列
スマホ：1列

### 2. 結果カードの前回歌唱情報を強調

「いつ振り」の根拠になるため、以下を拡大しました。

- 前回歌唱の日付
- 前回歌唱のイベント名

イベント区分・イベント種別・Day・公演・歌唱者などの補足情報は、
従来どおり小さめに表示します。

### 3. チェッカーの判定ロジック

v4.3.1から変更ありません。

- 曲ID順
- 曲＋基準日指定
- 基準日当日の歌唱は除外
- すべて／公式／ソロを独立判定

## 反映手順

1. GitHubへ4ファイルを反映
2. GitHub Pages反映後 Ctrl + F5
3. ホームにチェッカーカードが表示されることを確認
4. ランキングページからチェッカー導線が消えていることを確認
5. ホーム → チェッカーへ遷移
6. パンくずが「ホーム ＞ いつ振り歌唱チェッカー」になっていることを確認
7. 判定後、前回日付・イベント名が見やすくなっていることを確認
