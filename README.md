## 修正内容

### 0件データを除外

ランキング対象は記録が1件以上あるデータだけです。

- 曲：歌唱記録1件以上
- イベント：歌唱記録1件以上
- 会場：開催イベント1件以上
- 歌唱名義：歌唱記録1件以上

### 順位

検索・絞り込み・並べ替え後の表示順で、1位から振り直します。

### イベントランキング

画面から以下を削除しました。

- 延べ歌唱人数
- 平均歌唱人数
- 延べ歌唱人数順

内部APIの値は残しています。

### タブ別の並べ替え

曲：
- 歌唱回数が多い順
- 初披露が古い順
- 最終披露が新しい順
- 曲名順

イベント：
- 歌唱曲数が多い順
- 歌唱記録数が多い順
- 開催日が新しい順
- 開催日が古い順

会場：
- 開催イベント数が多い順
- 歌唱曲数が多い順
- 会場名順

歌唱名義：
- 歌唱記録数が多い順
- 歌唱曲数が多い順
- 出演イベント数が多い順
- 歌唱名義順

### 歌唱名義ランキング

見出しを次へ変更しました。

「歌唱名義別 歌唱記録数ランキング」

歌唱RAWに登録された名義単位で集計し、組み合わせ名義は別名義として扱う説明を追加しています。
