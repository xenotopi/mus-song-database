# v4.5.1：ホーム レスポンシブ修正版

## 修正目的
v4.5でスマホ表示は正常だった一方、
PCブラウザで一部要素が極端に細くなり、
文字が縦方向に折り返されるレイアウト崩れが発生していたため修正。

## 修正内容

### PC版（901px以上）
- HEROを最大1160pxで中央固定
- HERO本文幅を760px基準に固定
- 日本語テキストの縦書き・極端な折り返しを強制解除
- EXPLOREを2列の横長カードに固定
- EXPLORE内のタイトル・説明を横書き固定
- Todayを「日付カード + 内容」の2カラムに固定
- Numbersを「歌唱記録 + 3指標」の横並びに固定
- TOP5の最大幅を920pxへ
- Recentをコンテンツ幅いっぱいで表示
- About / Versionを2カラム横配置に固定

### スマホ
v4.5のモバイルレイアウトは維持。
今回の主要修正はPC向けメディアクエリ内で実施。
