## 注意

完全体回数は、現在のSong API仕様だけでは判定できません。
APIレスポンスに `completePerformanceCount` または `completeSongCount` が存在する場合は完全体率を表示し、
未連携の場合は「完全体判定データ未連携」と表示します。
