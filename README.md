# v2.9：イベント詳細ページ強化版

## Apps Script側

変更はありません。

既存のEvent API・Discover APIが返している情報を使って強化しています。

## GitHub側で上書き

- event.html
- assets/js/event.js
- assets/js/detail-context.js

## 主な追加内容

### このイベントの記録

- 登録曲数
- 初披露曲数
- 現時点で最終披露となっている曲数
- このイベントだけで歌われている曲数

### 歌唱名義の内訳

披露曲に登録された歌唱名義を集計し、
歌唱名義別の登場曲数として表示します。

個人単位への分解は行わず、RAWに登録された歌唱名義をそのまま扱います。

### イベントの発見

3列で表示します。

- このイベントだけの曲
- 初披露された曲
- 現時点で最後に歌われた曲

すべて曲詳細へ移動できます。

### 披露曲一覧

- 登録順の番号を表示
- 曲名から曲詳細へ移動
- 歌唱名義を表示
- 初披露バッジ
- 最終披露バッジ
- このイベントのみバッジ
- 条件別フィルター

フィルター：

- すべて
- 初披露
- 最終披露
- このイベントのみ

### 歌唱順について

APIの `songOrderIsSetList` がtrueの場合だけ実際の歌唱順として案内します。

falseまたは未設定の場合は、

「番号はデータベース上の登録順であり、実際の歌唱順とは限りません」

と明記します。

推測でセットリスト扱いにはしていません。

### 通信の安定化

Discover APIだけ失敗した場合でも、
イベント基本情報・歌唱統計・披露曲一覧は表示します。
