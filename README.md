# v4.5：ホームページ完成版

## 目的
ホームを「情報が並ぶダッシュボード」から、
μ'sの歴史を巡りたくなる入口へ再設計しました。

## 主な変更

### HERO
- 濃紺〜紫の大きなヒーローへ刷新
- 「μ'sの歌唱史を、記録から巡る。」を主メッセージ化
- 横断検索をHERO内の主要CTAとして強調

### EXPLORE μ's HISTORY
4つの主要入口を2×2の大型カードへ。
- 探す：横断検索
- 比べる：ランキング
- 振り返る：年別統計
- 調べる：いつ振り歌唱チェッカー

PC：2×2
スマホ：1×4

### TODAY IN μ's
- ホーム上位へ昇格
- 日付を大きく視覚化
- BirthdayはToday内で該当日のみ表示
- イベント／初披露／最終披露の既存ロジックを維持

### SECRET MEMORY
- Todayの発見要素として配置
- 現在のレアリティ・抽選アニメーション・排出率を維持

### DATABASE IN NUMBERS
- 歌唱記録数を最重要数字として大きく表示
- 管理曲数／イベント数／会場数を補助指標化

### DATA DISCOVERY
- ホームでは歌唱回数TOP5に集約
- 詳細ランキングページへのCTAを追加
- 会場ランキングはホームから削除（ランキングページへ集約）

### RECENT PERFORMANCES
- 最近歌われた曲を簡易タイムライン型UIへ変更
- 曲・イベント・会場への既存リンクは維持

### ABOUT / VERSION
- ホーム最下部に集約
- DB定義へのAbout導線とWeb v4.5・更新時刻を表示
