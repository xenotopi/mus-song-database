# v4.2.2：曲ページ歌唱名義リンク統一版

## 変更内容

曲詳細ページ内の歌唱名義リンクを、
v4.2.1で追加した歌唱名義詳細ページへ統一しました。

### 対象1：歌唱名義ランキング
ランキングの各行をクリックすると、

`singer.html?name=歌唱名義`

へ遷移します。

件数を見て「この○件はどの曲・イベントで歌ったのか」を
そのまま確認できます。

### 対象2：「この曲を巡る」→ 主な歌唱名義
従来の横断検索への遷移を廃止し、
同じ歌唱名義詳細ページへ遷移します。

表示文言も、

「この名義の関連曲・イベントを見る」

から

「この名義の歌唱履歴を見る」

へ変更しています。

## 動作確認

1. 任意の曲詳細を開く
2. 歌唱名義ランキングの任意の行をクリック
3. 歌唱名義詳細ページへ遷移する
4. 歌唱記録数・歌唱曲数・履歴が表示される
5. 「この曲を巡る」の主な歌唱名義からも同じ詳細ページへ遷移する
6. Ctrl + F5でキャッシュを更新
