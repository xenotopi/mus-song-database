# v4.4：曲詳細ページ完成版

## 実装した7点

1. 歌唱統計から「初披露日・最終披露日」を削除
   - 「この曲を巡る」の初披露・最終披露カードへ一本化

2. 「この曲を巡る」を強調
   - 初披露／最終披露のイベント名と日付を大きく表示

3. 「完全体率」に一般向け説明を追加
   - i アイコンから
     「この曲の本来の歌唱メンバーが全員揃って歌った記録の割合」
     と確認可能

4. 「歌唱イベント数」「歌唱記録数」の違いを補足
   - それぞれ i アイコンで説明

5. 「歌唱間隔の推移」に説明を追加
   - 前回歌唱から次に歌われるまでの日数
   - 直近8区間を表示していることを明記

6. 「この曲のいつ振りを調べる」を追加
   - 曲詳細から `gap-checker.html?song=Sxxxx` へ遷移
   - チェッカー側で曲を選択済みにする

7. PC／スマホレイアウト最終調整
   - 初披露／最終披露カード
   - 記録カード
   - チェッカーCTA
   - モバイル時のカード列数

2. 歌唱統計に初披露日／最終披露日が重複表示されないことを確認
3. 初披露／最終披露カードの視認性を確認
4. 歌唱イベント数・歌唱記録数の i を押して説明を確認
5. 完全体率の i を押して説明を確認
6. 歌唱間隔の説明文を確認
7. 「この曲のいつ振りを調べる」を押す
8. チェッカーで同じ曲が選択済みになっていることを確認
