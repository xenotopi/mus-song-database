## 主な追加内容

### この会場の記録

- 開催イベント数
- 公式・ソロ内訳
- 歌唱記録数
- 重複を除いた歌唱曲数
- 最多歌唱曲

### 会場利用データ

- 年別開催イベント数グラフ
- 数値目盛り
- よく登場する歌唱名義TOP10

歌唱名義はRAWに登録された文字列をそのまま集計します。

### 開催イベント一覧

- すべて
- 公式
- ソロ
- 開催年

で絞り込めます。

イベント名からイベント詳細へ移動できます。
絞り込み後の表示件数も確認できます。

### 既存機能

以下は維持しています。

- 前後会場
- 会場プルダウン
- 初開催・最終開催
- この会場で初披露された曲
- この会場で歌われた曲ランキング
- スクロール時の固定会場名
