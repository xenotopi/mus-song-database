# Web v4.6 — Detail Pages & Visual Consistency
## STEP3：曲詳細実装

### 実装内容
- 曲詳細HEROをv4.5ホームの世界観へ統一
- `SONG DETAIL` kicker追加
- HERO下部のアクセントラインを「正規歌唱者カラー」対応へ
  - APIから正規歌唱者情報を取得できた場合：該当メンバー色のみ
  - 正規歌唱者情報が取得できない場合：従来の9色をフォールバック表示
- 曲切替ナビを主要操作として維持・強化
- ページ内ナビを4分類へ整理
  - 基本情報
  - 歌唱記録
  - データ分析
  - 歌唱履歴
- 「この曲を巡る」を2×2構成へ
- いつ振りチェッカーを4枚目の探索カードとして統合
- SONG RECORDSの数字を強調
- 「データから見る、この曲。」へ分析セクション名を整理
- 年別歌唱推移の最多歌唱年を強調
- 公式・ソロ比較に割合表示を追加
- 歌唱間隔からいつ振りチェッカーへの導線追加
- 「同じ収録CD・メディア・区分の関連曲」をHTML/JSから削除
- 共演曲／よく歌われた会場は維持
- 歌唱履歴のイベント名・フィルター・もっと見るUIを改善
- PC／スマホレスポンシブ調整

### 正規歌唱者カラー
現在の曲APIが以下いずれかのフィールドを返す場合に自動反映します。
- `regularSingers`
- `originalSingers`
- `officialSingers`
- `regularSingerNames`
- `originalSingerNames`
- `regularSinger`
- `originalSinger`
- `正規歌唱者`
- `正規歌唱者名`

取得できない場合は表示欠損を避けるため9色表示へ戻します。
