# 歌唱ブランクランキングの派生データ

`data/gap-rankings.json` は正式Song117 snapshotのperformancesと正式Event snapshotから生成する表示専用データです。正本・snapshot・Revision metadataは変更しません。

正式snapshotを更新した後、公開前に次を実行してください。

```text
node tools/generate-gap-rankings.cjs
node --test tests/gap-rankings.test.cjs tests/gap-rankings-ui.test.cjs
```

生成器はcurrentの明示するoutput/dataRevision、全入力のfile/data hash・bytes・ID集合を検証し、生成中の入力変更を拒否します。`--check` は書込みなしで正式入力から再集計します。既存Static生成・current切替には接続していません。

入力変更時に派生データだけを流用しないでください。画面はcurrentとのRevision、snapshot manifest hash、派生payload hashが不一致ならランキングを表示せず再生成を要求します。APIへの117件先読みや架空のfallbackは行いません。

AはgapV2同様に基準日当日の歌唱を除外します。当日記録ありの曲も仮定比較の順位に入り得ますが、当日歌唱済みの注記を表示します。基準日前の記録がない曲は順位対象外です。

Bは基準日以前の異なる連続歌唱日を比較します。初歌唱以前は含まず、同日数の最大間隔は次の歌唱日が最新のものを採用。1曲1件、同日数は競技順位、表示順はSong ID昇順です。

区分はgapV2同様、正式イベントの「公式／ソロ」を優先し、不明時はperformanceのtypeを使用します。歌唱名義やイベント名から推測しません。同日レコードは日数計算だけ集約し、元記録数と関連イベントを保持します。
